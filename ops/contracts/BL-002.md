  - Aanroep `node scripts/check-doc-links.mjs --rev <commit>` (standaard `HEAD`). Leest alle getrackte `*.md` van die commit via `git ls-tree -r --name-only` en `git show <rev>:<pad>`. Bestaan wordt bepaald tegen de boom van die commit: een blob, of een map waar minstens één pad mee begint met `<p>/`. Het werkt nooit op de werkmap.
  - Regels binnen fenced code (```` ``` ```` of `~~~`) worden overgeslagen.
  - Klasse **A**: markdown-links en -afbeeldingen `[..](doel)` en `![..](doel)`, ook `<doel>` en `doel "titel"`. Overslaan: doelen met een schema (`^[a-z][a-z0-9+.-]*:`) en doelen die alleen een `#anker` zijn. `#…` en `?…` worden gestript en het doel wordt URL-gedecodeerd. Oplossen relatief aan de map van het bronbestand, of vanaf de repo-root als het doel met `/` begint. Een doel buiten de repo telt als gebroken.
  - Klasse **B**: inline code die exact een repopad is, ``` `((docs|ops|scripts|src|assets|output|work-sync)/[^`\s*<>{}|]+)` ```. Een achtervoegsel `:N` of `:N-M` en afsluitende `.,;)` worden gestript. Oplossen vanaf de repo-root.
  - Uitvoer op stdout: alleen gebroken verwijzingen, als TSV `bron<TAB>regel<TAB>klasse<TAB>doel<TAB>opgelost`, gesorteerd. Op stderr: `totaal <N>`. Exitcode 0.
- **Vergelijkingssleutel** voor "nieuw gebroken": de kolommen `bron`, `klasse` en `opgelost` (`cut -f1,3,5`). Regelnummers tellen niet mee.

## Risico en rollback
- Risico: de nachtbranch of later `main` botst met een keep-branch die een verplaatst document wijzigt. Mitigatie: criterium 5b. Git herkent renames bij een merge (`-M`), dus een late wijziging komt alsnog op het nieuwe pad terecht.
